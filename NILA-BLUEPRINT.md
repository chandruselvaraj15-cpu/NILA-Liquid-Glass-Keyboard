# NILA – Liquid Glass 3D Keyboard

## Vision
Build a premium Android keyboard with a Japanese anime AI companion named NILA.

## 1. Keyboard Design
- Fully transparent background with wallpaper visibility.
- Perfect circular floating 3D glass keys.
- Customizable RGB lighting and effects.
- Adjustable keyboard height, key size and spacing.
- Customizable haptic feedback and sound.
- Lightweight animations for low-memory devices.

## 2. NILA Anime Companion
- Japanese anime-style 3D female character.
- Cute and caring personality.
- Playful and naughty personality.
- Emotional and thoughtful personality.
- Adaptive personality based on conversation context.
- Facial expressions, blinking, gestures and lip-sync.
- Full-screen companion and floating mini-avatar modes.

## 3. Live Conversation
- Tamil, Tanglish and English voice interaction.
- Online AI conversation when explicitly requested.
- Natural voice responses and expressive reactions.
- Storytelling, jokes, games and casual conversations.
- User-controlled conversation memory.
- Honest companion behaviour: simulated emotions, not real consciousness.

## 4. Smart Keyboard
- Multilingual layouts and Unicode support.
- Word prediction and autocorrect.
- Swipe typing and long-press characters.
- Voice typing.
- Emoji, GIF and updated sticker search.
- Number row and language switching.
- Three selectable toolbar layouts.

## 5. Clipboard
- Local clipboard history.
- Long-term storage with user control.
- Pin, search, copy and delete items.
- Configurable storage limit.
- Sensitive data protection.

## 6. Password Security
- Encrypted local password vault.
- Fingerprint or PIN protection.
- Android Autofill integration.
- No automatic password collection.
- Never upload passwords to AI services.

## 7. Spacebar Gestures
- Tap to insert a space.
- Swipe left or right to switch recent languages.
- Long press to open language selector.
- Visual and haptic feedback.

## 8. Privacy and AI
- Local suggestions by default.
- Online AI only after user action.
- Disable learning and suggestions in password fields.
- No typing-history cloud upload by default.
- User-controlled data and memory settings.

## 9. Performance
- Optimize for Android phones with 4GB RAM.
- Battery Saver and lightweight mode.
- Offline basic keyboard functions.
- Optional online AI and media features.

## 10. Development Roadmap
Phase 1: Android keyboard foundation and basic typing.
Phase 2: Liquid glass circular keyboard and RGB effects.
Phase 3: Multilingual typing and clipboard.
Phase 4: NILA 3D anime avatar and voice.
Phase 5: AI conversation and adaptive personality.
Phase 6: GIF, stickers and secure password vault.
Phase 7: Performance optimization, testing and APK release.

## Platform
Native Android application.
Build and release APK using GitHub Actions.
